## Introduction

If you record an [unexplained]({{ 'unexplained/' | relative_url }}) sky sound that you think may be significant, the most important file is the one your recording device created—not the version you later upload to a social media platform. Online sharing is useful for finding other witnesses, but many services automatically compress audio and video, alter file formats, reduce resolution, or remove metadata. These changes can make later analysis more difficult and may prevent others from verifying when, where and how the recording was made. For anyone documenting unusual aerial sounds, preserving the untouched original should therefore be treated as a basic evidence-preservation step rather than an afterthought. NASA's independent study of unidentified anomalous phenomena (UAP) similarly emphasised that complete sensor data and metadata are essential because missing contextual information greatly limits scientific evaluation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/forensic-science/digital-and-multimedia-evidence" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[nist.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-title">digital and multimedia evidence</span><span class="citation-popover-snippet">September 13, 2013...</span><span class="citation-popover-meta">Published: September 13, 2013</span></span></span>

The safest approach is simple: never let your first upload become your only copy.

<div class="content-enhancement content-enhancement--checklist" markdown="1">

* Leave the original file exactly as your device created it.
* Copy it to another location before editing, trimming or uploading.
* Keep the original filename if possible.
* Avoid opening the file in applications that automatically re-encode media on export.
* Store at least two copies on different devices or storage media.

</div>

This preserves both the media itself and the information embedded within it. Depending on the device, metadata may include the recording time, file creation details, device model, GPS location (if enabled), recording settings and other technical information that can help reconstruct the circumstances of the event. Apple, for example, notes that original photo and video files may include metadata such as date, time, location and device information, while also providing options to preserve or alter that information during sharing.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://support.apple.com/en-ie/guide/iphone/iphf28f17237/ios" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: support.apple.com">[Apple Support]</a><span class="citation-popover" role="note"><span class="citation-popover-source">support.apple.com</span><span class="citation-popover-title">Support Share photos and videos on i Phone</span><span class="citation-popover-snippet">Apple SupportShare photos and videos on iPhone - Apple Support (IE)...</span></span></span>

## Why Social Media Copies Are Usually Poor Evidence

A recording that sounds convincing online may be much less useful for technical review than the original stored on your phone or recorder.

Most major sharing platforms optimise uploaded media for storage and streaming efficiency. Depending on the service, this may involve:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Lowering audio or video bitrates.
* Changing the codec or container format.
* Reducing image or video resolution.
* Recompressing the file, introducing new artefacts.
* Removing or rewriting metadata.
* Renaming the file.

</div>

Research examining major photo-sharing platforms has shown that uploaded images are routinely transformed, with changes extending beyond visible quality to filenames and other digital characteristics. Such processing is valuable for platform efficiency but makes downloaded copies less representative of the original recording.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://arxiv.org/abs/2302.12133" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: arxiv.org">[arXiv]</a><span class="citation-popover" role="note"><span class="citation-popover-source">arxiv.org</span><span class="citation-popover-snippet">Practical Analyses of How Common Social Media Platforms and Photo Storage Services Handle Uploaded ImagesFebruary 23, 2023...</span><span class="citation-popover-meta">Published: February 23, 2023</span></span></span>

For an unexplained sky sound, even subtle changes matter. Compression can soften faint background noises, alter frequency content or introduce artefacts that complicate later spectral analysis. Likewise, stripped metadata may remove information needed to compare independent recordings from different witnesses.

## Create Backups Before Any Editing

Many people instinctively trim silence, increase volume or apply noise reduction before sharing. While these edits may make the recording easier to hear casually, they permanently change the evidence unless the original has already been preserved.

A practical workflow is:



<img src="{{ "/assets/images/ufo_noises_37edd1_record_unexplained_s_403e7e_original_file_preser_6c3c5d-Illustration-2-dark.svg" | relative_url }}" alt="File Preservation illustration 2" data-theme-src-dark="{{ "/assets/images/ufo_noises_37edd1_record_unexplained_s_403e7e_original_file_preser_6c3c5d-Illustration-2-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/ufo_noises_37edd1_record_unexplained_s_403e7e_original_file_preser_6c3c5d-Illustration-2-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. Record the event.
2. Immediately duplicate the file.
3. Archive the untouched original.
4. Perform any editing only on the duplicate.
5. Clearly label edited versions.

</div>

Using descriptive filenames such as:

* `Original_2026-07-31_2148.wav`
* `Edited_NoiseBoost_v1.wav`

helps prevent accidentally overwriting the source recording.

This approach mirrors established digital evidence practice, where preserving an unmodified original allows later reviewers to distinguish between observed data and subsequent processing. NIST's work on digital and multimedia evidence likewise emphasises the importance of maintaining original digital material for reliable forensic examination.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/forensic-science/digital-and-multimedia-evidence" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[nist.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-title">digital and multimedia evidence</span><span class="citation-popover-snippet">September 13, 2013...</span><span class="citation-popover-meta">Published: September 13, 2013</span></span></span>

## Preserve Metadata Whenever Possible

Metadata is often invisible to the user but can be highly valuable during later review.

Depending on the recording device, useful metadata may include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Date and time of recording.
* Device model.
* Recording format and sample rate.
* GPS coordinates (if enabled).
* Orientation and other sensor information.
* Original filename and creation timestamp.

</div>

If you intentionally remove location information before publishing publicly for privacy reasons, retain a private copy containing the complete metadata. That way, you can still provide the original file to researchers or investigators if needed without exposing personal information online.

Some platforms and sharing methods preserve more original information than others. Apple, for instance, allows users in certain sharing workflows to send the original media with edit history and metadata instead of a converted version, although this depends on the chosen sharing option.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://support.apple.com/en-ie/guide/iphone/iphf28f17237/ios" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: support.apple.com">[Apple Support]</a><span class="citation-popover" role="note"><span class="citation-popover-source">support.apple.com</span><span class="citation-popover-title">Support Share photos and videos on i Phone</span><span class="citation-popover-snippet">Apple SupportShare photos and videos on iPhone - Apple Support (IE)...</span></span></span>

## Share Copies, Not the Master File

Think of the original recording as a master archive.

For public discussion, create a separate sharing copy. This allows you to:


<div class="content-enhancement content-enhancement--phrase-stack" markdown="1">

* Reduce file size for easier uploading.
* Blur personal information if necessary.
* Trim irrelevant sections without affecting the archive.
* Add captions or annotations.
* Normalise playback volume for listeners.

</div>

If someone later requests the original for detailed analysis, you still have the untouched source available.

This distinction is especially important if multiple investigators independently examine the recording. Everyone can compare their analyses against the same unaltered file instead of different edited versions.

## A Small Habit That Can Preserve Your Best Evidence

Most recordings of unusual sky sounds ultimately have ordinary explanations, ranging from aircraft and weather to industrial activity. Regardless of the outcome, preserving the original recording ensures that any investigation begins with the highest-quality evidence available.

Uploading to social media should therefore be viewed as the final step in documentation rather than the first. By keeping an untouched master copy, making secure backups before editing, and understanding that online platforms frequently recompress media and alter metadata, you maximise the chances that your recording can be assessed fairly and accurately if questions arise later.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://arxiv.org/abs/2302.12133" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: arxiv.org">[arxiv.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">arxiv.org</span><span class="citation-popover-snippet">Practical Analyses of How Common Social Media Platforms and Photo Storage Services Handle Uploaded ImagesFebruary 23, 2023...</span><span class="citation-popover-meta">Published: February 23, 2023</span></span></span>

    var template = String(cfg.url_template || 'https://www.ebay.com/sch/i.html?_nkw={query}');
    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
